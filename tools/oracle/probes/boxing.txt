# Boxing in San Mona on the user's saves. No save stands in D5, so boxingsquad moves the listed mercs (and
# their groups) to D5 with grid insertion, loads the sector with SetCurrentWorldSector, unpauses and gives the moved mercs
# CalcActionPoints. The other commands run the original's functions on the loaded club: boxingstart is Darren's
# START_BOXING_MATCH action, boxingstep teleports a soldier and runs BoxingMovementCheck while a match is tracked,
# boxingattack ProcessImplicationsOfPCAttack with the given usAttackingWeapon, boxingend EndBoxingMatch, boxinggetup
# BeginSoldierGetup, boxingexit ExitBoxing, boxingrecord TriggerEndOfBoxingRecord, boxingdecide DecideAction (status=1 runs
# DecideAlertStatus first), boxingpoints CalcActionPoints and CalcNewActionPoints, boxingfacts CheckFact for 210, 230,
# 231 and 368, boxingset writes the boxing globals and a soldier's life, breath, collapse, APs, boxer flag or a slot.
