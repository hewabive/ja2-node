# Bombs, mines, booby traps and the panic AI (0027). Every command but bombmap prints the draws, its result, the soldier
# it names with every enemy in the sector (position, APs, keys, x-ray state, inventory with traps and attachments; for
# enemies the alert status, action and data, new situation and stored path; for our mercs the wisdom and explosives gains
# with their stat change chances and successes), and the bomb state: the world bomb slots with each object's bomb fields,
# the explosion queue with timestamps relative to the JA2 clock, the queue flags and its person, the tile mine flags, the
# panic state, the attack busy count and sight flags, the ignited explosions, the message boxes waiting for an answer and
# the booby trap globals.
#
# bombmap loads a map bare (LoadWorld with its PreRandom item rolls traced) and runs InitPanicSystem after the reset of
# InitializeTacticalStatusAtBattleStart. armbomb makes an object with CreateItem (attach= adds attachments, action= the
# action value, setting= runs ArmBomb, det=, freq=, bombitem=, owner= (default 1, a map bomb), trap=, tolerance=, known=,
# disabled= and alarm= set the fields) and adds it with AddItemToPool (visible= default buried, flags= default armed bomb).
# bombsoldier sets soldier fields, moves him (grid=), fills his hand (hand=, attach=) or a pocket (slot=, item=).
# stepon runs SetOffBombsInGridNo, bombfrequency SetOffBombsByFrequency (who=-1: no soldier), decaybombs
# DecayBombTimers, bombqueue advances the JA2 clock by ms= and runs HandleExplosionQueue steps= times, bombreset frees the
# explosions, the queue, the busy count and the boxes. groundcheck runs NearbyGroundSeemsWrong (mode=raw) or the static
# CheckIfNearbyGroundSeemsWrong; bombpickup runs HandleSoldierPickupItem; plantbomb runs HandleSoldierDropBomb (or
# HandleSoldierUseRemote with use=remote); all of them run a pending stop-time quote callback and the item locator it
# starts, then answer the message boxes in order (answers=yes,no,1..4). xray runs ActivateXRayDevice (off=1:
# TurnOffXRayEffects). panicinit, panicset, chosenone, possiblychosen, panicai, pulltrigger (code 762 of Soldier_Ani.cc)
# and usedetonator (AI_ACTION_USE_DETONATOR of ExecuteAction) drive the panic AI; minepath runs FindBestPath and PlotPath.
