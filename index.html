ja2-node

Non-commercial reimplementation of Jagged Alliance 2. Milestone M4: the strategic layer.

  • Tactical sandbox — the server's sandbox session: select a merc, click to walk, right-click to run
  • Strategic map — start a campaign, watch the clock, plot routes, enter sectors
  • Asset browser — VFS files, STI sprites and stubs
  • Map viewer — tactical maps of the original and the stub world
