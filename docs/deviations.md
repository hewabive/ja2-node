# Deliberate deviations from the original

Every place where ja2-node knowingly behaves differently from JA2 Stracciatella (the behaviour
reference, see `01-architecture.md` D1). Add an entry whenever a port departs from the source.

| Area | Original | ja2-node | Why |
|---|---|---|---|
| Random numbers | `mt19937` + `uniform_int_distribution`; `Random` and `PreRandom` share one engine with cosmetic code | xoshiro128**, multiply-shift range mapping, separate `pre`, `main` and cosmetic streams | Determinism and save/replay; outcomes keep the original semantics (`01` §3.6) |
| Timing | Wall-clock timers that never catch up; frame-rate dependent bullets, burst cadence and real-time AI slice | Fixed 5 ms ticks; bullets advance N tiles per tick; a fixed number of real-time AI soldiers per pass | Outcomes independent of FPS and CPU (`04` §3) |
| Speech | Quote duration is the audio length (speech on) or 60 ms per character | Always 60 ms per character in the simulation | The simulation must not depend on audio (`04` §3) |
| Watchdogs | 15 s AI deadlock breaker, 25 s UI busy breaker | Not ported | A hang is a bug and must fail tests |
| Real-time pause | Pause masks the screen; no orders while paused | Orders may be issued while paused (manual driver) | Agent API (`04` §4.3) |
| Map files | 178 of 261 maps carry trailing bytes after the last section | Ignored and reported as `trailingBytes` | Same as the original loader, which stops reading after the schedules |
| Pathfinder RNG | `FindBestPath` draws `Random(4)` for every skip-list node it inserts | No draws; the open list is a heap with the same pop order | Path choice never depended on the draws (`07` §3.2) |
| Frame timers | `TIMECOUNTERDONE` against the wall clock, polled every 5 ms | Absolute game-ms deadlines checked on 5 ms ticks, same reset points | Same frame cadence without wall-clock jitter (`03` §7) |
| Sandbox population | Garrison size and stats from strategic state, `CalcDifficultyModifier`, `SortSoldierInitList` order, campaign progress | Fixed garrison of 4 ARMY troops, difficulty modifier 30 (stats and equipment), placement groups in map order, progress 0; `GenerateRandomEquipment` is ported | Temporary for the sandbox; replaced when the strategic layer exists (M4) |
| Doors | `DOOR_BUSY` blocks a door while its tile animation plays; the player's perceived door state may lag; door shadows animate | No busy window; the perceived state equals the real one; door shadow tiles keep their map graphic | Temporary; the door opening, passing and closing behind follow the original |
| Waiting sweet spot | `FindGridNoFromSweetSpotThroughPeople` ranks by cell-coordinate distance after a reachability flood | Plain Pythagorean ranking over occupied-or-free tiles without the flood | Temporary; only used when a blocked final destination must be replaced |
| Soldier frame on turning | `usAniFrame` keeps the old direction block until the next frame code | The client derives the sprite from (script frame, current direction), so a new facing shows at once | At most one frame of visual difference (`06` §1.3) |
| Enemy glow | Enemies pulse red every 3 s and jump to the top z at the peak; unseen ones are drawn grey | Not drawn yet; soldiers use the normal shade | Cosmetic; later with the UI |
| Vision and hearing modifiers | Light sprites, goggles, NIGHTOPS, extended ear, walkman, camouflage, smoke | Ambient light only (day 3), no gear or traits | Temporary until items and lighting are simulated |
| Fog of war | `RevealRoofsAndItems` also reveals items, wireframes and slanted roofs | Tiles and room roofs only; items, wireframes and slanted roofs come with M3/M4 | Temporary |
| Turn-based UI lock | `SetUIBusy`/`UnSetUIBusy` lock the interface while the selected merc acts; the selected merc is a UI choice | Commands are accepted only when it is our turn, no attack is resolving and no other merc of ours is acting; `selected` is the merc of the last accepted command | The API has no cursor or selection; same set of legal orders (`10` §9) |
| Interrupt prompt | No modal box: the "Interrupt for…" message and the UI unlock for the interrupting mercs | `advance` stops with `decision` while our interrupt is open; `endTurn` closes it | Lets an agent know which mercs may act (`10` §9) |
| Continue a move | `CheckForMercContMove` requires the merc to be selected and on screen | No screen check: a new `move` re-plans for any merc of ours | UI-only condition |
| Enemy sighted on their turn | 3 s wall-clock pause (`GameScreen.cc`) | 3000 ms of game time | All timers run on game time |
| Unseen soldiers in combat | Animation delay 0 for soldiers neither visible nor rendered visible, with a fade-out state machine | Unseen soldiers keep their normal animation speed; no fade state yet | Temporary: only changes how many ticks an enemy turn takes, not its outcome |
| Turn-based hooks | Bleeding, drugs, phobias, boxing, vehicles, reinforcements, capture on defeat, end-of-turn decays of smells, bombs, smoke and light | Not ported yet | Temporary, M3 |
| Object union | `OBJECTTYPE` stores gun ammo, money, bomb and key fields in one 12-byte union aliased with `bStatus[]` | Separate fields; `status[]` is the per-object status | Aliasing only shows when a stack of guns is split, which ends up identical |
| Soldier creation draws | Nightops trait chance, battle sound, camouflage for enemies with a kit, face items moved from big pockets to the face | Not drawn or applied yet | Temporary; the draw order of the ported steps (body, level, stats, equipment, palettes) follows the original |
| Bullet flight | `MoveBullet` is gated by a 2–3 ms wall clock and called once per frame, so flight time and burst overlap follow the frame rate | One tile per 5 ms tick at the start of the tick, the first tile inside `FireWeapon`; knives every 30 ms | Outcomes independent of FPS (`11` §3.3) |
| Game events | Fire events run in the frame's event pump | Same queue order, drained after each tick's soldier pass | Same order without a frame loop (`11` §1.2) |
| Our merc's death | The barrier is released after the portrait and skull UI animation (12 × 160 ms wall clock) | A fixed 1920 game ms after opcode 440 | UI timing has no game clock |
| Cosmetic draws in attacks | Curses `Random(10)`/`Random(40)`, the laugh `Random(3)`, blood pools `Random(3)`/`Random(4)`, stat-change messages `Random(100) < 25` and the silent skill-check curse `Random(100) < 40` share the gameplay `Random` | Not drawn | They only pick sounds, quotes and blood graphics (`11` §12.4) |
| Blood and smell | Wounds leave blood pools that decay and that creatures can smell | Not simulated | Temporary, with creatures |
| Corpses | A corpse is a structure: bullets aimed at its tile stop in it and large corpses block sight | Corpses are records without a structure; the dying soldier keeps his person structure until 440 | Temporary, M3 |
| Window hits | The window structure swaps to its cracked and shattered partners and the map tile graphic changes | The structure swaps; the map graphic stays | Temporary; the client has no tile updates yet |
| Shooting locks and explosive structures | A bullet can damage a door lock (`PreRandom(2)`, lock table); an explosive structure blows up on `Random(2)` | No lock damage and no lock draws (no lock table yet); the explosive structure draw is made but nothing explodes | Temporary, with the lock table and explosions |
| Falling off a roof | An incapacitated soldier next to a roof edge falls off (`CheckSoldierHitRoof`) | Not ported | Temporary, with roof climbing |
| Attack refusals | `HandleItem` refuses for good guys, buddies and rebels, imprints rocket rifles and may cancel on a "no line of fire" quote | Not ported; the agent decides with `estimateAttack` | UI-level checks |
| Implications of an attack | `ProcessImplicationsOfPCAttack` runs civilian-group, militia, boxing and NPC script rules | Neutral civilians and friendly militia turn hostile; our own mercs never fire back out of combat | Temporary, with civilian groups and NPC scripts |
| Miss animation in water | The splash tile has its own frame count from the tileset data | The ground miss timing (425 ms) is used everywhere | Rare; the release time only shifts the barrier |
| Multi-tile turning | `MultiTiledTurnDirection` picks the turn direction that keeps a multi-tile structure placeable | The quickest direction; a blocked step still stops the turn | Only creatures, vehicles and prone soldiers are multi-tile |
| Combat AI specials | Panic AI and alarms, Queen/Joe/Warden, boxers, tanks, the Tixa gas mask draw, surrender offers, `SearchForItems` for ammo and weapons; throw, stab and spread-burst evaluation (`PreRandom(3)` per target heard last turn, `Random(2)` in the spread burst) | Not ported: the hooks report "not possible" and draw nothing; the throw weapon choice keeps its `PreRandom(2)`; `SearchForItems` returns NONE, a gun without ammo is still flagged AI-unusable and stowed | Temporary, M3 (throws and melee) and M4 (strategic specials) |
| Armed civilian without ammo | `DecideActionBlack` loops forever when a civilian's `CanNPCAttack` returns anything but TRUE, FALSE or NOWEAPON | Treated as "cannot attack" | The original hangs |
| AI and roofs | Climb points, MOVE_TO_CLIMB and CLIMB_ROOF; disturbances and friends on another level | No climb point is ever found (`NOWHERE`); path costs across levels are 0 | Temporary, with roof climbing |
| AI light and gas | `InLightAtNight`, `FindNearbyDarkerSpot`, `InGasOrSmoke`, `FindNearestUngassedLand` | Never lit, never gassed; deep water still triggers LEAVE_WATER_GAS | Temporary, with lighting and smoke |
| Recalculated path cost | `RecalculatePathCost` re-costs the global path buffer of the last `FindBestPath` call | Re-costs the soldier's stored path | Same path in the cases where it is used (`NewDest` right after the path was stored) |
| GoAsFar fallback | `std::shuffle` of the eight directions | Fisher–Yates on the main stream | Same distribution; `std::shuffle` is implementation-defined |
| AI threat value | `CalcManThreatValue` skips boxers and soldiers not on duty; creature spit adds its gas damage to the shot estimate | No boxing or assignments yet, so every placed soldier counts; the gas bonus is 0 | Temporary, with boxing, assignments and smoke effects |
| Map-edge escapes | `FindFleeSpot` stores the traversal quote action so a fleeing soldier can leave the map | The action is computed but not stored; nobody leaves the map | Temporary, with sector exits (M4) |
| AI path-cost cache | `gubAIPathCosts` is a global that keeps values from earlier searches | A fresh array per search | Only differs when the budget minus the start cost is exactly 0, which only happens below RED |
