# data/externalized

JSON data copied unchanged from JA2 Stracciatella `assets/externalized/` at commit `ae6bf01`
(<https://github.com/ja2-stracciatella/ja2-stracciatella>): item, weapon, army, strategic, dealer and
NPC script tables plus the `strings/` and `translation_tables/` directories. Stracciatella extracted
these tables from the Jagged Alliance 2 source code; they are covered by the SFI-SCLA (see
`../../LICENSE`). Do not edit by hand; re-copy from a newer Stracciatella snapshot instead.
